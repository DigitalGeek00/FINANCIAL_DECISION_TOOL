# Financial Decision Tool

A Python application for exploring financial concepts and evaluating investment scenarios through interactive calculations.

The project started as a collection of standalone scripts and is evolving into a modular command-line application. Its main goals are to improve code organization, maintainability, input handling, and the reliability of financial calculations.

## Overview

Financial Decision Tool provides calculations and analysis related to interest, investment growth, recurring contributions, investment fees, taxes, and investment comparisons.

The application is designed as a personal learning project focused on Python development, financial modelling, and software design fundamentals.

**Disclaimer:** This project is for educational purposes only and does not provide financial advice. Results are estimates based on user-provided inputs and simplified assumptions.

## Features

### 1. Interest Calculations

- **Simple interest:** Calculate generated interest and final capital over a specified period.
- **Compound interest:** Estimate investment growth through compounding.

### 2. Investment Analysis

Estimate the impact of investment fees and taxes on investment performance.

- Calculate gross capital and gross profit before fees and taxes.
- Estimate accumulated Total Expense Ratio (TER) fees.
- Estimate the total impact of TER fees on final capital, including the effect of lost future growth.
- Estimate taxes on positive profits remaining after TER fees.
- Calculate final net profit and net capital.

### 3. Annual Investment Evolution

- Display capital evolution year by year.
- Calculate gross investment return.
- Calculate final capital and accumulated return.
- Support investment periods containing a fractional year.

### 4. Dollar-Cost Averaging (DCA)

Model an initial investment combined with recurring contributions.

- Calculate total invested contributions.
- Estimate the growth of the initial capital.
- Estimate the growth generated by recurring contributions.
- Calculate final capital, investment return, and return on invested capital (ROI).

### 5. Investment Comparator

Compare investment alternatives using two approaches:

- **Case A-B:** Compare two investments with different initial capital amounts, durations, and annual return assumptions.
- **Different returns:** Evaluate multiple annual return scenarios for the same initial capital and investment period.

### 6. Input Validation

- Validate positive numeric inputs for capital, time, annual return, contributions, and taxes.
- Allow zero TER values.
- Handle non-numeric input using exception handling.
- Convert percentage inputs and TER values into decimal representations for calculations.
- Use `0` as the termination signal when entering return scenarios.

### Module Responsibilities

- **`main.py`:** Application entry point.
- **`cli.py`:** Displays menus, collects user choices, calls the relevant functions, and presents results.
- **`inputs.py`:** Handles console input and converts user-provided values into the formats expected by the calculations.
- **`validations.py`:** Contains reusable validation rules.
- **`calculations.py`:** Implements the core financial calculations independently of the command-line interface.
- **`tests/`:** Intended for automated tests as the testing suite is developed.
- **`legacy/`:** Preserves previous versions of the project to document its development.

This modular structure makes it easier to test calculations independently and provides a foundation for future integration with other interfaces.

## Financial Model Assumptions and Limitations

The calculations use simplified models and should not be interpreted as exact predictions of real investment performance.

### Interest and Annual Returns

- Annual return rates are assumed to remain constant during the investment period.
- Compound interest uses the formula for a constant annual return.
- The annual evolution calculation estimates the return for a fractional year proportionally to the fraction of the year, rather than applying fractional-year compounding.

### TER Fees

- TER is expressed as a proportion of investment capital.
- For full years, investment growth is applied before the estimated TER fee is deducted.
- For fractional years, the fee is estimated proportionally to the fraction of the year.
- This approach is a simplified approximation and does not reproduce the exact daily expense accrual reflected in a real fund's net asset value.

### Taxes

- The model assumes taxes are applied when the investment is sold.
- Taxes are calculated only on positive profits remaining after estimated TER fees.
- Actual tax treatment depends on the investor's circumstances and applicable tax regulations. The model does not represent every possible tax situation.

### DCA

- Annual returns are converted into an equivalent monthly rate.
- Recurring contributions are modelled at monthly intervals.
- Actual market returns fluctuate, and the results are not guaranteed.
- The model does not account for inflation, transaction costs, changing contribution amounts, or fluctuating market prices.

### Running the Application

Run the application from the directory containing `main.py`:

```bash
python main.py
```
